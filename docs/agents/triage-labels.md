# Triage Labels

This project uses the default triage label vocabulary.

## Label Mapping

| Role | Label |
|------|-------|
| Needs triage | `needs-triage` |
| Needs more info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

## Usage

The `triage` skill will apply these labels when moving issues through the triage workflow.
