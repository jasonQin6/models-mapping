# Issue Tracker

This project uses **GitHub Issues** as its issue tracker.

## Configuration

- **Tracker**: GitHub Issues
- **Repository**: https://github.com/jasonQin6/models-mapping.git
- **CLI**: `gh` (GitHub CLI)

## Usage

Skills like `to-tickets`, `triage`, and `to-spec` will use `gh issue create`, `gh issue list`, etc. to manage issues.

## PRs as a Request Surface

**Disabled** — PRs are not automatically added to the triage queue.

To enable: set `prs_as_request_surface: true` in this file.
